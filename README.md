# IFNTUOG Schedule Bot

Telegram-бот для перегляду розкладу Івано-Франківського національного технічного університету нафти і газу (НУНГ). Бот отримує розклад із сервісу деканату, показує його у вигляді зображень і тексту, підтримує пошук, налаштовувані сповіщення та збереження даних у PostgreSQL.

**Бот у Telegram:** [@NUNG_RozkladBot](https://t.me/NUNG_RozkladBot)

**Репозиторій:** [Dr34mChas3r/IFNTUOGrozkladTELEGRAMbot](https://github.com/Dr34mChas3r/IFNTUOGrozkladTELEGRAMbot)

## Можливості

- Розклад групи на сьогодні, завтра, тиждень або вибрану дату; зображення містить час пар, аудиторії, викладачів та, за наявності, QR-коди/посилання.
- Вибір групи та інтерактивна навігація за допомогою Telegram-кнопок.
- Пошук занять у межах групи, а також глобальний пошук викладача або аудиторії.
- Керування відображенням вибіркових предметів і темою зображення (світла/темна).
- Щоденні, тижневі та сповіщення про зміни в розкладі; сповіщення можуть закріплюватися в чаті (до п'яти повідомлень, якими керує бот).
- **[НОВЕ] Сповіщення за 5 хвилин:** Бот автоматично надсилає сповіщення-нагадування за 5 хвилин до початку дистанційних загальноуніверситетських пар. Функція працює **тільки в приватних повідомленнях** з ботом.
- PostgreSQL для налаштувань користувачів і кешу розкладу; кеш використовується як резерв, коли сервіс розкладу недоступний.
- Режим налагодження з повідомленнями про проблеми отримання розкладу та використання кешу.

## Вимоги

- Python 3.10 або новіший (рекомендовано; версію Python окремо не закріплено в requirements.txt).
- Доступ до Telegram Bot API та токен, створений через [@BotFather](https://t.me/BotFather).
- PostgreSQL і рядок підключення `DATABASE_URL`.

## Встановлення та запуск

```bash
git clone https://github.com/Dr34mChas3r/IFNTUOGrozkladTELEGRAMbot.git
cd IFNTUOGrozkladTELEGRAMbot
python -m venv .venv
```

Активуйте віртуальне середовище, а тоді встановіть залежності:

```bash
# Windows PowerShell
.\.venv\Scripts\Activate.ps1

# macOS/Linux
source .venv/bin/activate

python -m pip install -r requirements.txt
```

Створіть у корені проєкту файл `.env` (не додавайте його до Git) і заповніть власними значеннями:

```env
BOT_TOKEN=токен_від_BotFather
DATABASE_URL=postgresql://користувач:пароль@хост:5432/назва_бази
```

Підключення до PostgreSQL виконується з обов'язковим SSL. Переконайтеся, що база доступна з середовища, де запускається бот.

Запустіть бота з кореня проєкту:

```bash
python bot_global.py
```

Файл шрифту `Roboto-Regular.ttf` постачається в репозиторії. Якщо його не вдасться завантажити, генератор використовує стандартний шрифт Pillow; вигляд кирилиці та емодзі при цьому може відрізнятися.

## Команди

| Команда | Призначення |
| --- | --- |
| `/start` | Привітання та головне меню |
| `/group <назва>` | Вибрати групу, наприклад `/group КІ-24-1` |
| `/today` | Розклад на сьогодні |
| `/tomorrow` | Розклад на завтра |
| `/week` | Розклад на поточний тиждень |
| `/date ДД.ММ` | Розклад на дату в поточному році, наприклад `/date 19.12` |
| `/search <текст>` | Пошук занять у вибраній групі |
| `/search_all <текст>` | Глобальний пошук викладача або аудиторії |
| `/electives` | Керування вибірковими предметами |
| `/settings` | Тема та налаштування сповіщень |

Після `/start` доступні кнопки для перегляду розкладу, вибіркових предметів і налаштувань. Вибір групи та перемикання параметрів у груповому чаті доступні адміністраторам; у приватному чаті бот дозволяє керувати власними налаштуваннями, зокрема вимикати чи вмикати нагадування про пари (опція доступна лише у приваті).

## Сповіщення та час

Значення в `bot_global.py`:

```python
DAILY_NOTIFICATION_TIME = time(4, 0)
WEEKLY_NOTIFICATION_TIME = time(14, 0)
WEEKLY_NOTIFICATION_DAY = 0  # Monday
SCHEDULE_CHECK_INTERVAL = 30 * 60
MAX_PINNED_MESSAGES = 5
```

Щоденне сповіщення налаштоване на 04:00, тижневе — на понеділок о 14:00, а перевірка змін — кожні 30 хвилин. **Нагадування за 5 хвилин до пари** перевіряються автоматично кожну хвилину. У коді для JobQueue не задано окремий часовий пояс, тому бібліотека використовує UTC за замовчуванням. Тижневий job запитує сім днів, починаючи із завтрашньої дати. Якщо потрібен інший час або календарний діапазон, змініть ці налаштування/логіку та перевірте їх на своєму хостингу.

## Розгортання

Бот працює через long polling. Для постійної роботи розмістіть його на сервері або іншому хостингу, який підтримує фонові процеси та PostgreSQL; задайте `BOT_TOKEN` і `DATABASE_URL` у змінних середовища. У репозиторії немає готового `Procfile`, Dockerfile чи конфігурації systemd — за потреби їх потрібно створити для обраного хостингу.

## Примітки

- Не публікуйте `.env`, токен бота чи облікові дані бази.
- Репозиторій не містить окремого набору автоматизованих тестів; перевіряйте роботу бота в Telegram із налаштованою базою та актуальним розкладом.
- Джерело розкладу — зовнішній сервіс деканату, тому його доступність і формат даних не контролюються цим проєктом.
