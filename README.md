

# 🎓 IFNTUOG Schedule Bot (НУНГ Розклад)

Сучасний Telegram-бот для перегляду розкладу занять Івано-Франківського національного технічного університету нафти і газу (НУНГ).

Бот автоматично отримує дані з API деканату, генерує зручні зображення розкладу з емодзі, надсилає автоматичні сповіщення, закріплює важливі повідомлення та надійно зберігає всі налаштування користувачів у PostgreSQL.

## 🔥 Можливості

* 🖼 **Графічний розклад:** Генерація стильних картинок з розкладом на день або тиждень. Динамічна зміна сітки (від 5 до 7 днів) залежно від наявності пар у вихідні. Повна підтримка кольорових емодзі.
* 📚 **Вибіркові предмети:** Гнучке керування предметами з позначкою `*(в)` та Військовою підготовкою. Вимкнені користувачем предмети залишаються в розкладі, але отримують спеціальний бляклий дизайн (`[НЕ ОБРАНО]`), щоб не відволікати увагу.
* 💾 **Надійна база даних:** Використання PostgreSQL (напр., Heroku Postgres) для збереження налаштувань чатів, вибіркових предметів та кешу розкладу. Дані не зникають при перезапуску бота.
* 📅 **Гнучка навігація:** Перегляд розкладу на сьогодні, завтра, поточний тиждень або будь-яку дату.
* 🔔 **Автоматичні сповіщення:**
  * **Щоденна розсилка** розкладу на сьогодні.
  * **Тижнева розсилка** розкладу на наступний тиждень.
  * Сповіщення автоматично **закріплюються** в чаті (максимум 5 повідомлень).
* 🔄 **Моніторинг змін:** Відстежує зміни в розкладі та повідомляє про них у реальному часі.
* 🔎 **Пошук:** Локальний (`/search`) та глобальний (`/search_all`) пошук предметів, викладачів та аудиторій.
* 🛠 **Режим Дебагу:** Спеціальний перемикач для адміністраторів, що дозволяє отримувати системні повідомлення про стан парсера та використання резервного кешу.

## 🛠 Встановлення

### 1. Клонування репозиторію

```bash
git clone [https://github.com/Dr34mChas3r/IFNTUOGrozkladTELEGRAMbot.git](https://github.com/Dr34mChas3r/IFNTUOGrozkladTELEGRAMbot.git)
cd IFNTUOGrozkladTELEGRAMbot

```

### 2. Встановлення залежностей

Переконайтеся, що у вас встановлені необхідні бібліотеки (включно з `pilmoji` для генерації емодзі та `psycopg2-binary` для роботи з БД):

```bash
pip install -r requirements.txt

```

### 3. Налаштування середовища

Створіть файл `.env` у кореневій папці проєкту та додайте ваш токен і підключення до бази даних:

```env
BOT_TOKEN=ваш_токен_від_BotFather
DATABASE_URL=postgresql://user:password@host:port/dbname

```

**Важливо:** Переконайтеся, що у системі встановлений шрифт `Roboto-Regular.ttf` (або вкажіть шлях до свого шрифту у `image_gen.py`). Без нього текст на картинках може відображатися некоректно.

### 4. Запуск бота

```bash
python3 bot_global.py

```

## 🤖 Команди бота

| Команда | Опис |
| --- | --- |
| `/start` | Головне меню та привітання |
| `/group [Назва]` | Встановити групу для чату (напр. `КІ-24-1`) |
| `/today` | Отримати картинку розкладу на сьогодні |
| `/tomorrow` | Отримати картинку розкладу на завтра |
| `/week` | Отримати картинку розкладу на тиждень |
| `/electives` | 📚 Керування вибірковими предметами |
| `/date [ДД.ММ]` | Розклад на конкретну дату |
| `/search [текст]` | Локальний пошук (у межах групи) |
| `/search_all [текст]` | Глобальний пошук (викладач / аудиторія) |
| `/settings` | Налаштування сповіщень (тільки для адмінів) |

## ⚙️ Налаштування

### Доступні параметри в коді (`bot_global.py`):

```python
DAILY_NOTIFICATION_TIME = time(4, 0)      # Час щоденних сповіщень
WEEKLY_NOTIFICATION_TIME = time(14, 0)    # Час тижневих сповіщень
WEEKLY_NOTIFICATION_DAY = 0               # День тижня для тижневих (0 = Понеділок)
SCHEDULE_CHECK_INTERVAL = 30 * 60         # Інтервал перевірки змін (30 хв)
MAX_PINNED_MESSAGES = 5                   # Максимум закріплених повідомлень

```

### Налаштування сповіщень через бота:

У меню `/settings` адміністратори можуть увімкнути/вимкнути:

* ✅ **Сповіщення про зміни** — миттєві повідомлення при зміні розкладу.
* ✅ **Щоденно о 7:00** — розклад на сьогодні кожного ранку.
* ✅ **Щотижнево** — розклад на наступний тиждень.
* 🛠 **Режим дебагу** — технічні сповіщення про доступність сервера деканату.

## 🤖 Деплой на Heroku (або Systemd)

Бот повністю адаптований для роботи на **Heroku**.

1. Додайте аддон **Heroku Postgres**.
2. Heroku автоматично підтягне змінну `DATABASE_URL`.
3. Використовуйте `Procfile` із вмістом: `worker: python bot_global.py`.

Для запуску на власному VPS (через `systemd`), просто вкажіть `DATABASE_URL` у блоці `Environment=` вашого `nung_bot.service` файлу.
